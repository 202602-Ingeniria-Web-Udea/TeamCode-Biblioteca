### Biblioteca TeamCode

Biblioteca TeamCode es una aplicación web para gestionar una biblioteca. Permite consultar libros disponibles, registrar préstamos, devoluciones y reservas, y llevar el control de las existencias.

Tiene dos roles: el administrador gestiona libros y usuarios, y el usuario consulta el catálogo y gestiona sus préstamos y reservas.
